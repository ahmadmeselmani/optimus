# Optimus Handbook

Documentation for Optimus, a lightweight terminal interface for local Ollama
models. Pages in `docs/` cover usage, configuration, the retained architecture,
current scope, and manual checks. Keep them aligned with shipped behavior.

Built with Docusaurus. From this directory:

```bash
npm install
npm run start
npm run build
```

The build generates static content in `build/`. From the repository root,
`make handbook-dev` starts the dev server and `make handbook-build` validates
the site.
